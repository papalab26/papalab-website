# 小小廚師 · Little Chef（獨立試玩版 v2）

本目錄為獨立實驗，不修改正式首頁、草原遊戲、其他遊戲或部署設定。單一 `index.html` 包含完整介面、Canvas 客人動畫、SVG 食物插畫、遊戲邏輯及音效，不需安裝套件，不使用付費 API 或外部圖片／CDN。

## 開啟與操作

下載 `index.html`，以支援 JavaScript 的 Chrome、Safari 或其他現代瀏覽器開啟。聊天程式或手機檔案 App 的內嵌預覽可能不執行 JavaScript；若畫面不動，請改用完整瀏覽器。也可把本目錄交由任何靜態網頁伺服器提供，但目前不部署正式網站。

1. 點「開門營業」，允許瀏覽器由點擊啟動音效；客人會唸出訂單。
2. 點客人臉右側的喇叭圖示，可以重聽。訂單對話框只有播放圖示，不顯示英文答案或食物圖片。
3. 第一、二關從三張圖片中選一張；第三、四關選一種主食與指定數量的配料。
4. 點食物或食材只做選取，不播放發音或點選提示音。點已選的項目可拿回；選另一種主食會替換原主食，配料滿額後再選會替換最早選的配料。
5. 選好後點送餐圖示。送餐後不能再改單，等客人反應演完才結算，再換排隊的下一位客人。
6. 每關完成 5 筆正確訂單即可過關。上方 `1 / 4` 按鈕可自由選擇四個試玩關卡；切換或重玩本關會清除該關當次進度，金幣保留。

## 四關內容與單字

| 關卡 | 規則 | 單字 |
| --- | --- | --- |
| 1 料理點餐 | 聽一種料理，三選一 | Fried rice、Ramen、Spaghetti、Pizza、Burger、Sandwich、Curry rice、Sushi |
| 2 飲料點餐 | 聽一種飲料，三選一 | Cola、Milk、Orange juice、Guava juice、Apple juice、Coffee、Water、Tea |
| 3 加一種配料 | 主食＋一種配料 | Rice、Noodles、Bread；配料見下列 |
| 4 三樣小料理 | 主食＋兩種不同配料 | Egg、Corn、Carrot、Tomato、Chicken、Cheese、Lettuce、Mushroom |

使用簡單食物、飲料與食材英文；保留需求中指定的炒飯、拉麵、義大利麵與芭樂汁等名稱。第一、二關的料理與飲料使用洗牌題庫，避免連續重複；組合關卡避免連續出現相同食材組合。主食／配料的點選順序不影響答案。

## 金錢與客人反應

- 初始 30 元，送對固定 `＋10`，送錯固定 `−10`。每張訂單只結算一次。
- 為使扣款與收款金額始終相同，餘額不足仍扣完整 10 元，可以顯示負數；不因此強制結束，仍可繼續接客賺回。
- 送對會品嚐、微笑、眼睛發亮，說「Yummy! Thank you!」。
- 送錯會從多種反應中隨機挑選，避免連續相同，不採用兩種結果固定各 50% 的機制。
- 反應包含困惑、直接嫌棄、聞過後拒絕、吃下後吐出／喝下後噴出、吃喝後鼓腮噁心；延後發現時，先正常吃喝，才變綠和出現少量卡通水滴，最後扣款離開。
- 反應期間不能換關卡，避免跳過結算。瀏覽器隱藏時暫停遊戲動畫與音樂。

## 音效與儲存

英文使用瀏覽器 `speechSynthesis`，免費背景音樂與提示音使用 Web Audio 合成。實際英文發音需要裝置的英文語音支援，聲音品質取決於系統；雲端測試只驗證語音呼叫，沒有實機聽音驗證。音樂只啟動一個計時器，靜音會停止語音與音樂。

使用 `localStorage` 的獨立 key `papalab-little-chef-trial-v1` 儲存金幣、各關進度、目前關卡與聲音偏好，不讀寫既有遊戲記錄。儲存被封鎖時仍可遊玩。關閉頁面不保存尚未演完的訂單，重新開啟會重新點餐。

## 已驗證與限制

執行：

```sh
python3 experiments/little-chef/tests/play.py
```

環境需要 Python Playwright 與 `/usr/bin/chromium`。測試使用本地 HTML／攔截路由，不需對外服務。

已通過：四關實際點餐、八種料理與八種飲料的選圖、僅從訂單發音、所有關卡訂單只有圖示、點選選項不發音、配料替換及無序組合、正負 10 元延後且單次結算、五單過關、客人排隊遞補、多種隨機反應及臉色改變像素、靜音與單音樂計時器、存檔、無外部 HTTP 資源與 JavaScript 錯誤。

已通過 `320×568`、`390×844`、`844×390`、`1280×850` 四種尺寸下的四關觸控送餐、主要按鈕至少 44px 與無水平溢出。短螢幕可垂直捲動；直向組合關卡使用較精簡的場景與食材卡，保留客人臉部辨識度。人工檢視手機與桌面畫面。

未驗證：實體手機的 FPS、各系統實際英文語音與音樂聽感、聊天 App 內嵌瀏覽器的完整功能。未部署正式網站，未修改其他遊戲。
