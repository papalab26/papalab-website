# 鬥塔大戰：四關版本

本版本保留既有靜態 HTML 架構，由儲存庫 main 分支透過 GitHub Pages 發布。`index.html` 沒有外部素材依賴，可下載後直接用瀏覽器開啟試玩。

- 第一關「士兵初戰」：士兵；我方生命 200、敵方生命 60；起始 3 點，每題答對 +1 點。
- 第二關「坦克增援」：士兵、坦克；雙方城堡生命 400；起始 6 點。
- 第三關「空中支援」：士兵、坦克、飛機；雙方城堡生命 700；起始 9 點。
- 第四關「機器人決戰」：全部四種兵種；雙方城堡生命 1000；起始 12 點。

兵種由關卡累積開放，玩家與敵方遵守同樣限制，取代原先按答對題數解鎖的規則。選擇簡單或困難加法後從第一關開始，第一關固定 5 以內加法；答錯保留原題，錯誤選項停用，可再嘗試。第二關起使用所選的 10 或 20 以內加法。電腦起始點數與玩家相同（3、6、9、12），備戰期間也會獨立答題賺點數；第一關保留每 14～18 秒嘗試派兵、場上最多 2 名存活敵兵的入門保護。保留 30 秒備戰及兵種價格與能力。

摧毀敵方城堡後按「下一關」前進；失敗可重試本關；第四關通關後可以重新從第一關開始，或回主選單。每關重新計算城堡生命與點數，清空兵力、子彈、特效與待執行回呼。`LEVELS` 集中管理名稱、生命，`UNLOCK` 定義兵種開放關卡。

驗證：

```sh
python3 games/math/2.TowerBattle/tests/levels.py
```

測試需要 Python Playwright 與 `/usr/bin/chromium`，檢查雙方四關兵種限制、購買、過關／下一關、失敗／重試、最終通關／重玩、狀態與回呼清理、加法模式、手機版面與觸控。四關攻城測試使用真實 `choose`、`buy`、`stepFrame` 邏輯加速模擬，不代表已在實體手機完成驗證。

出題以完整加法題庫打散抽取，优先避開最近三個算式，嚴格避免相鄰完全相同或只是左右互換的題目。各選項位置重新打亂。

坦克有履帶、車輪、車身震動、砲管後座與砲口閃光；飛機有螺旋槳、上下浮動、機翼傾斜與投彈艙動畫；機器人有交替步伐、手臂擺動、眼睛、能量核心與射擊後座。`artTick` 和 `fireAnim` 由同一遊戲更新迴圈推進，暫停時凍結，只有美術變動，不改變碰撞及兵種能力。

追加驗證：

```sh
python3 games/math/2.TowerBattle/tests/improvements.py
```

檢查 2,400 題的範圍、相鄰不重複和四個有效選項；驗證幼兒關重試、獎勵與慢速操作通關；比較 Canvas 像素以确认三種載具移動／攻擊動畫有變化，暫停不繼續動畫。入門難度尚未由實際 5 歲孩子試玩驗證。

四關答對皆 +1 點。所有選項都限制在目前題目範圍：第一關 1～5、後續簡單模式 1～10、困難模式 11～20；四個數字互不重複，且恰好一個正確答案。未開放的兵種直接隱藏；已開放但點數不足的兵種反灰且不能購買，點數補足後恢復。

點數、選項上限、鎖定兵種隱藏與不足點數反灰的專項驗證：`python3 games/math/2.TowerBattle/tests/points_options.py`。

背景音樂改由既有遊戲迴圈做 0.16 秒前瞻排程。每次停止時會歸零並斷開該次背景音樂音量節點，停止及斷開所有旋律、顫音、低音和節拍來源；重新開始建立獨立節點，不會重新啟用舊音符。沒有另外的背景音樂循環計時器。專項驗證：`python3 games/math/2.TowerBattle/tests/music_overlap.py`，包括原音軌真實訊號、四關切換及通關重玩舊輸出保持靜音、靜音／暫停／選單清理及曲目循環邊界。

電腦以獨立打散題庫在背景解答當關加法，每題完成 +1 點，沒有自動免費發點：1+2 等小數字題基準 3 秒、5+4 等 10 以內較難題基準 4 秒，20 以內題約 5～5.5 秒；每題在基準值上下浮動 10%。玩家與電腦的題庫進度互不影響。備戰時計算，暫停／切換分頁時凍結，重試／換關／回主選單時清除舊題。

出兵計畫使用可開放兵種的打散購買袋（士兵2、坦克2、飛機2、機器人1），正常開局先派士兵，第二次購買優先當關新兵種。沒點數就存錢，不會一直改買便宜兵；遇到飛機且缺少防空時會優先準備飛機。取消以前「先出5次兵才能買飛機」和「60秒內不出機器人」限制，第二關起約每3～5秒作一次購買決定。

專項驗證：`python3 games/math/2.TowerBattle/tests/cpu_strategy.py`，包含 3,200 次獨立抽題、3／4秒時間基準、單題只加一點、備戰計算與暫停清理、存錢購買、真實排程中的飛機／機器人出場與防空反應。
